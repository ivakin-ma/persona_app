# Генератор и анализатор архетипов пользователей

Прикладная программа по теме: модуль хранения данных прототипа приложения для генерации архетипов пользователей при проектировании пользовательских интерфейсов.

## Что делает программа

1. Позволяет вручную добавить архетип пользователя.
2. Позволяет быстро сгенерировать 1 или много архетипов, например 10000 за один клик.
3. Сохраняет архетипы в SQLite.
4. Показывает список и карточку выбранного архетипа.
5. Считает SQL-статистику по базе.
6. Отдельно запускает нейросетевой анализ уже сохранённых архетипов и выдаёт советы для UI/UX.

## Важное изменение

Нейросеть НЕ используется при генерации пользователей.

Правильная схема:

```text
JSON-справочники / ручной ввод
        ↓
быстрое создание архетипов
        ↓
SQLite база данных
        ↓
SQL-статистика
        ↓
нейросеть анализирует накопленные данные
        ↓
выводы и рекомендации для UI/UX
```

## Запуск

```bash
python main.py
```

## Нейросеть

В коде используется модель из исходного описания:

```text
DeepVK/GeRaCl-USER2-base
```

Она применяется только для анализа и советов по уже имеющимся архетипам. Если `transformers` или `torch` не установлены, программа не падает, а использует резервную rule-based логику.

Для установки зависимостей:

```bash
pip install -r requirements.txt
```

## Файлы

- `main.py` — графический интерфейс Tkinter.
- `database.py` — SQLite, таблицы и CRUD.
- `generator.py` — генерация архетипов из JSON.
- `neural_advisor.py` — нейросетевой анализ, статистика и советы.
- `data/*.json` — справочники.
